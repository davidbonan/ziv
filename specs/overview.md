# ziv — Overview

## 1. Goal
A light clone of Adobe Lightroom: import photos (RAW included), develop them
non-destructively, retouch locally through masks, export.

## 2. Feature set
| # | Feature | Spec |
|---|---------|------|
| F1 | Photo import — RAW + JPEG/PNG/TIFF | to write |
| F2 | Global development — exposure, tone, white balance, curves, HSL, color grading | to write |
| F3 | Local adjustments — masks (brush, linear / radial gradient, shapes), each carrying its own adjustments | to write |
| F4 | Precise zone masks — hair, eyes, skin… generated by segmentation | to write |
| F5 | AI sharpening | to write |
| F6 | Export | to write |

A feature has no spec until `/spec` writes `specs/<feature>.md`.

## 3. Locked decisions
Changed only through a new ADR (`specs/adr/`).

| Decision | Choice | ADR |
|----------|--------|-----|
| Language | Rust, stable toolchain, edition 2024 | 0001 |
| UI | `eframe` / `egui` 0.36 | 0001 |
| Image engine | `wgpu` (through eframe's wgpu backend), headless-capable | 0001 |
| RAW decoding | `rawler` (pure Rust, LGPL-2.1) | 0001 |
| Platform | macOS Apple Silicon first; code kept portable, other OSes untested | 0001 |
| Crate layout | single `ziv` crate, lib + bin | 0001 |
| Edits | non-destructive: source file never written | 0001 |
